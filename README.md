# LingoTuner for OpenCart — User Guide

This repository provides user-facing documentation for the LingoTuner OpenCart translation workflow. It does not contain proprietary extension source code.

## What LingoTuner helps with

LingoTuner helps OpenCart administrators manage translation requests for selected store content, including products, categories, attributes, and options.

The workflow includes selecting content, choosing a target language, reviewing translations with back-translation, tracking request status, and fetching completed translations into OpenCart.

## Basic workflow

1. Configure the required LingoTuner API key.
2. Enable the extension.
3. Select a content type and the relevant items.
4. Choose a target language and start the translation.
5. Review the translated content and use back-translation where available.
6. Monitor the request status.
7. Fetch completed content into OpenCart.
8. Verify the result on the storefront.
